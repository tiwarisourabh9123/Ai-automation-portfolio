A  collection of production-ready **AI Agents, Hybrid RAG Applications, and End-to-End Workflow Automation** systems built using **Python, Google Gemini API, Qdrant, Flask, n8n, Docker, and JavaScript**.

Each folder in this repository contains a standalone, documented project with architecture notes, setup instructions, and live execution screenshots.

## Projects Included
* **[`restaurant-rag-ai-concierge`](./restaurant-rag-ai-concierge)** — Hybrid RAG restaurant concierge, table reservation, and conversational food ordering system (Python, Flask, Qdrant, Google Gemini API, Pydantic).
* **[`Inbound-lead-qualification-engine`](./Inbound-lead-qualification-engine)** — Automated inbound lead scoring, AI enrichment, and CRM routing workflow (n8n, Docker, Google Gemini API, JavaScript, Google Sheets).
