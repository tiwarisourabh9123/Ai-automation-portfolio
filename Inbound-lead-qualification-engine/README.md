# AI Inbound Lead Qualification & Routing Engine

An event-driven B2B lead qualification, scoring, and sales intelligence pipeline built with **n8n**, **JavaScript**, **Google Gemini**, and **Google Sheets**.

This workflow eliminates manual lead triage by capturing inbound B2B inquiries via REST webhooks, calculating a deterministic fit score (`0–100`), filtering out low-priority noise, generating tailored sales pitch recommendations with Google Gemini for high-priority prospects, and logging enriched lead records to a central tracking sheet in real time.

---

## Business Problem & Solution

* **The Problem:** Sales and operations teams waste hours manually reviewing inbound form submissions, researching prospect companies, and writing custom discovery-call briefs—resulting in slow response times on high-value enterprise leads and wasted effort on unqualified inquiries.
* **The Solution:** An automated 5-stage orchestration pipeline that qualifies every incoming lead in under 5 seconds, prioritizes Tier-1 B2B buyers (`Score >= 70`), uses an LLM to draft actionable technical pitch points based on the prospect's exact use case, and logs everything into an organized tracker ready for immediate outreach.

---

## System Architecture

```text
[Inbound Webhook: POST /webhook/lead-inbound]
                      │
                      ▼
        [1. Code in JavaScript]
        • Sanitizes & normalizes payload fields
        • Computes 0–100 fit score (Size + Budget + Domain)
        • Assigns Tier 1 / Tier 2 / Tier 3 classification
                      │
                      ▼
           [2. If Node Router]
           (initialScore >= 70)
             │              │
     (FALSE) ▼              ▼ (TRUE — Tier 1 High Priority)
      [Stop / Ignore]  [3. Google Gemini (Message a Model)]
                       • Synthesizes prospect pain points
                       • Generates Executive Summary & 3 tailored solutions
                                    │
                                    ▼
                       [4. Google Sheets (Append Row)]
                       • Logs full contact details, lead score, tier,
                         use case notes, and AI sales strategy

```

## Deterministic Lead Scoring Model

Every inbound payload is evaluated by the **Code in JavaScript** node using a 100-point weighted scoring rubric before any AI tokens are consumed:

| Criterion | Condition | Points Awarded |
| --- | --- | --- |
| **Baseline** | Valid inbound submission | `+20` |
| **Company Size** | `>= 100` employees | `+30` |
|  | `25 – 99` employees | `+20` |
|  | `5 – 24` employees | `+10` |
| **Annual Budget** | `>= $20,000` | `+35` |
|  | `$10,000 – $19,999` | `+25` |
|  | `$3,000 – $9,999` | `+15` |
| **Email Domain** | Corporate domain (excludes `@gmail.com`, `@yahoo.com`, `@hotmail.com`, `@outlook.com`) | `+15` |

### Priority Tiers & Routing Logic

* **Tier 1 — High Priority (`Score >= 70`):** Routed down the `TRUE` branch to **Google Gemini** for AI strategic analysis and appended to the **Hot Leads - AI Qualification Tracker** Google Sheet.
* **Tier 2 — Medium Priority (`Score 45 – 69`):** Filtered at the **If** gate (`FALSE` branch) to conserve LLM API quota.
* **Tier 3 — Nurture (`Score < 45`):** Filtered at the **If** gate (`FALSE` branch) without triggering downstream notifications or sheet writes.

## Setup & Deployment Guide

1. **Prerequisites:**
* Self-hosted **n8n** instance (Docker or VPS) or n8n Cloud.
* **Google Gemini (PaLM) API Key** from Google AI Studio.
* **Google Cloud OAuth2 Credentials** with Google Sheets API enabled.


2. **Import the Workflow:**
* Open n8n and create a new workflow.
* Click **`...` → Import from File** and upload `workflow.json`.


3. **Configure Credentials & Target Sheet:**
* Open the **Message a model** (Gemini) node and select your Gemini API credential.
* Open the **Append row in sheet** node, connect your Google Sheets OAuth2 account, and select your target spreadsheet and worksheet.


4. **Activate & Test:**
* Toggle the workflow to **Published / Active**.
* Send a test `POST` request to `http://localhost:5678/webhook/lead-inbound` using `payload-sample.json`:
```powershell
Invoke-RestMethod -Uri "http://localhost:5678/webhook/lead-inbound" -Method Post -ContentType "application/json" -InFile "payload-sample.json"

```
